Alternation

Jan 02, 20264 min read

Alternation is a generalization of nondeterminism that has proven to be useful in understanding relationships among complexity classes, simplifying various proofs in complexity theory

Definition: An alternating Turing machine is a nondeterministic Turing machine whose states are divided into universal states and existential states; when we run an alternating Turing machine on an input

  • A universal state is accepting if all of its children are accepting
  • An existential state is accepting if any of its children are accepting
  • The input is accepted if the start node is designated accepting

An alternating Turing machine with only existential states is a classic nondeterministic Turing machine

Definition: ATIME(t(n)) is the set of languages decided by an O(t(n)) time alternating Time machine, and ASPACE(f(n)) is the set of languages decided by an O(f(n)) space alternating Turing machine

We also define AP, APSPACE, and AL as polynomial time, polynomial space, and logarithmic space respectively

Example:
A tautalogy is a Boolean formula that always evaluates to 1

We can easily decide TAUT={⟨ϕ⟩∣ϕ is a tautology} by universally selecting all assignments to the variables of ϕ, requiring all branches to evaluate to 1

Note that this is also in coNP, and any problem in coNP can be easily shown to be in AP by the same principle

Furthermore, AP appears to be more powerful than NP

For example, we can solve MIN-FORMULA, which is thought to not be in NP or coNP

“On input ⟨ϕ⟩:

  1. Universally select all formulas ψ that are shorter than ϕ
  2. Existentially select an assignment to the variables of ϕ
  3. Evaluate both ϕ and ψ
  4. Accept if the formulas evaluate to different values, otherwise reject”

This should give a clear sense of the expressive power of alternation

Alternation also allows us to establish some fascinating relationships between time and space

Theorem: For f(n)≥n, ATIME(f(n))⊆SPACE(f(n))⊆ATIME(f2(n)), and for f(n)≥logn, ASPACE(f(n))=TIME(2O(f(n)))

As a result, AL=P, AP=PSPACE, and APSPACE=EXPTIME

We prove this as four individual ⊆ relations

Lemma: For f(n)≥n, ATIME(f(n))⊆SPACE(f(n))

We convert an alternating time machine M to a deterministic machine S by simulating a depth-first search on M‘s computation tree to determine which nodes in the tree are accepting

A naive stack (in terms of space) would store one configuration at each level

Instead, we can store only the nondeterministic choice at each level, and simply replay the computation to recover the state

Lemma: For f(n)≥n, SPACE(f(n))⊆ATIME(f2(n))

We use the YIELD algorithm from the proof of Savitch’s Theorem, running the recursive algorithm with universal branching

The maximum time used on any branch is O(f(n)) to write a configuration at each level, and there are log2df(n)=O(f(n)) levels, so this algorithm runs in alternating time O(f2(n))

Lemma: For f(n)≥logn, we have ASPACE(f(n))⊆TIME(2O(f(n)))

The deterministic machine computes a graph of the computation of M on w, for nodes that use at most df(n) space for the appropriate constant d

Then the machine repeatedly scans and marks off nodes in this graph
There are 2O(f(n)) nodes in the graph, and scanning the graph that many times still takes 2O(f(n)) time

Lemma: For f(n)≥logn, we have ASPACE(f(n))⊇TIME(2O(f(n)))

We use the tableau setup described here

The tricky thing here is that our alternating machine S has very little space to work with, only pointers into a tableau for the deterministic M on w

We get around this by existentially guessing the contents of the bottom left cell, which tells us if M accepts w

We verify our guess by existentially guessing the contents of the parents, checking whether their contents fits the transition function, and then universally verifying these guesses recursively

Hence, we never need to store more than a single pointer to a cell in the tableau, so this uses space log2O(f(n))=O(f(n))

Definition: A Σi​-alternating Turing machine is an alternating Turing machine that on every input and on every computation branch contains at most i runs of universal or existential steps, starting with existential steps

An Πi​-alternating Turing machine is similar but starts with universal steps

We define Σi​TIME(f(n)), Πi​TIME(f(n)), Σi​SPACE(f(n)), and Πi​SPACE(f(n)) accordingly

This lets us define a more fine-grained hierarchy within PSPACE

Definition: The polynomial time hierarchy is the collection of classes Σi​P=⋃i​Σi​TIME(nk) and Πk​P=⋃k​Πi​TIME(nk)

Definition: PH=⋃i​Σi​P=⋃i​Πi​P
