Conditional Expectation

Suppose f(x,y)=P{X=x,Y=y}, fX​(x)=∑y​f(x,y), and ∑x​f(x,y)
We define E(Y∣X)(x)=fX​(x)∑y​yf(x,y)​

If X1​,…,Xn​,Y have a joint probability density function f, and g(x1​,…,xn​)=∑y​f(x1​,…,xn​,y)
E(Y∣X1​,…,Xn​)(x1​,…,xn​)=g(x1​,…,xn​)∑y​yf(x1​,…,xn​,y)​

We can easily define continuous analogues,
fX​(x)=∫−∞∞​f(x,y)dy, fY​(y)=∫−∞∞​f(x,y)dx
E(Y∣X)(x)=fX​(x)∫−∞∞​yf(x,y)dy​
And E(Y∣X1​,…,Xn​)(x1​,…,xn​)=fX1​,…,Xn​​(x1​,…,xn​)∫−∞∞​yf(x1​,…,xn​,y)dy​

E(Y∣X1​,…,Xn​) is characterized by two properties,

  1. E(Y∣X1​,…,Xn​) depends only on the values of X1​,…,Xn​ (we can write it as ϕ(X1​,…,Xn​) for some ϕ). We call E(Y∣X1​,…,Xn​) measurable with respect to X1​,…,Xn​.
  2. Suppose A is an event that depends on X1​,…,Xn​ and IA​ is the indicator function of A. E(YIA​)=E[E(Y∣X1​,…,Xn​)IA​].

Measure theoretic treatments of probabilities define conditional expectation as the unique random variable satisfying these two properties

As shorthand, we write E(Y∣Fn​), where Fn​ denotes the information contained in X1​,…,Xn​

This gives us E[E(Y∣Fn​)]=E(Y)
And E(aY1​+bY2​∣Fn​)=aE(Y1​∣Fn​)+bE(Y2​∣Fn​)

If Y is a function of Fn​ then E(Y∣Fn​)=Y

For any Y, if m<n, then E(E(Y∣Fn​)∣Fm​)=E(Y∣Fm​)

If Y is independent of Fn​, E(Y∣Fn​)=E(Y)

If Y is any random variable and Z is a random variable that is measurable with Fn​, then E(YZ∣Fn​)=ZE(Y∣Fn​)

Example:
Suppose X1​,X2​,… are i.i.d. with μ and let Sn​=X1​+⋯+Xn​
Let Fn​ denote the information in X1​,…,Xn​ and suppose m<n

E(Sn​∣Fm​)=E(X1​+⋯+Xm​∣Fm​)+E(Xm+1​+⋯+Xn​∣Fm​)
E(X1​+⋯+Xm​∣Fm​)=Sm​
E(Xm+1​+⋯+Xn​∣Fm​)=E(Xm+1​+⋯+Xn​)=(n−m)μ
So E(Sn​∣Fm​)=Sm​+(n−m)μ

Example:
Assume the same as above, but μ=0⟹Var(Xi​)=E(Xi2​)=σ2
E(Sn2​∣Fm​)=E([Sm​+(Sn​−Sm​)]2∣Fm​)
=E(Sm2​∣Fm​)+2E(Sm​(Sn​−Sm​)∣Fm​)+E((Sn​−Sm​)2∣Fm​)

E(Sm2​∣Fm​)=Sm2​
E((Sn​−Sm​)2∣Fm​)=E((Sn​−Sm​)2)=Var(Sn​−Sm​)=(n−m)σ2
E(Sm​(Sn​−Sm​)∣Fm​)=Sm​E(Sn​−Sm​∣Fm​)=Sm​E(Sn​−Sm​)=0

Altogether, E(Sn2​∣Fm​)=Sm2​+(n−m)σ2

Example:
Consider the first example where Xi​ is Bernoulli and i≤m

E(Xi​∣Sn​)=nSn​​
E(Sm​∣Sn​)=E(X1​∣Sn​)+⋯+E(Xm​∣Sn​)=nm​Sn​

Consider E(Y∣Xα​,α∈A) where Xα​,α∈A is an infinite collection of random variables
Let F denote the information in {Xα​}
Z is F-measurable if knowledge of {Xα​} determines Z, i.e. Z=ϕ(Xα1​​,…,Xαn​​) for some ϕ and some finite subcollection, or if Z is a limit of such random variables

As an example, say Y,X1​,X2​,… are independent random variables and X1​,X2​,… are i.i.d. with the standard normal distribution, while Y is unknown, define Zj​=Xj​+Y, and let Fn​ denote the information in Z1​,…,Zn​

One cannot determine Y given any finite set Fn​, however Y is F∞​ measurable since Y=limn→∞​nZ1​+…Zn​​

An event A is F-measurable if IA​ is an F-measurable random variable
E(Y∣F) is defined as the unique F-measurable random variable Z such that E(YIA​)=E(ZIA​) for all F-measurable events A

I.e. E(YIA​)=E(E(Y∣F)IA​)

Martingales

A martingale is a model of a fair game

We let {Fn​} denote an increasing collection of information, a collection of random variables An​ such that Am​⊂An​ if m<n, meaning we don’t lose information

The increasing sequence of Fn​ is known as a filtration

A sequence of random variables M0​,M1​,M2​,… with E(∣Mi​∣)<∞ is a martingale with respect to {Fn​} if

  1. Each Mn​ is measurable with respect to Fn​ and
  2. E(Mn​∣Fm​)=Mm​ for all m<n

The second condition is equivalent to E(Mn​−Mm​∣Fm​)=0 and can be proven by showing E(Mn+1​∣Fn​)=Mn​

Example:
Mn​=Sn​−nμ is a martingale with respect to Fn​
E(Mn+1​∣Fn​)=E(Sn+1​−(n+1)μ∣Fn​)=E(Sn+1​∣Fn​)−(n+1)μ=(Sn​+μ)−(n+1)μ=Mn​

Example:
Suppose P{Xi​=1}=P{Xi​=−1}=21​

Say we double our bet every instance and stop when we win and let Wn​ denote the winnings or losses up through n flips of the coin,
P{Wn+1​=1∣Wn​=1}=1

If the first n flips have turned up tails, Wn​=−(2n−1)
P{Wn+1​=1∣Wn​=−(2n−1)}=21​
P{Wn+1​=−(2n+1−1)∣Wn​=−(2n−1)}=21​

We can verify E(Wn+1​∣Fn​)=Wn​, so Wn​ is a martingale with respect to Fn​

We can generalize this, such that we make a bet Bn​ on the nth flip, measurable on Fn−1​ and Wn​=∑j=1n​Bj​Xj​

We can let Bn​ be negative, corresponding to betting the coin will come up tails

E(Wn+1​∣Fn​)=E(∑j=1n+1​Bj​Xj​∣Fn​)=E(∑j=1n​Bj​Xj​∣Fn​)+E(Bn+1​Xn+1​∣Fn​)
=Wn​+Bn+1​E(Xn+1​)=Wn​

So the general form is also a Martingale

Example:
Consider an urn with a red ball and a green ball. Every time one draws a ball, it is returned along with another of the same color. Let Xn​ denote the number of red balls in the urn after n draws

This is a Markov chain,
P{Xn+1​=k+1∣Xn​=k}=n+2k​
P{Xn+1​=k∣Xn​=k}=n+2n+2−k​

Mn​=n+2Xn​​ is a martingale

E(Xn+1​∣Xn​)=Xn​+n+2Xn​​
Since this is a Markov chain, all relevant information in Fn​ is contained in Xn​,
E(Mn+1​∣Fn​)=E((n+3)−1Xn+1​∣Xn​)
=n+31​[Xn​+n+2Xn​​]=n+2Xn​​
=Mn​

Mn​ is called a submartingale if E(Mn​∣Fm​)≥Mm​ and a supermartingale if E(Mn​∣Fm​)≤Mm​

Example:
Let Xn​ be a finite Markov chain, with v(x)=E(f(XT​)∣X0​=x) where T is the optimal stopping rule

Mn​=v(Xn​) is a supermartingale with respect to X0​,X1​,…

Optional Sampling Theorem

The optional sampling theorem states that you cannot beat a fair game, however it’s a bit subtle

We say T is a stopping time with respect to {Fn​} is for each n, {T=n} is measurable with respect to Fn​

Under certain conditions, E(MT​)=E(M0​)

Suppose M0​,M1​,… is a martingale with respect to {Fn​} and suppose T≤K is a stopping time which is bounded, then E(MT​∣F0​)=M0​

MT​=∑j=0K​Mj​I{T=j}
E(MT​∣FK−1​)=E(MK​I{T=K}∣FK−1​)+∑j=0K−1​E(Mj​I{T=j}∣FK−1​)
E(Mj​I{T=j}∣FK−1​)=Mj​I{T=j}
E(MK​I{T=K}∣FK−1​)=E(MK​I{T>K−1}∣FK−1​)
=I{T>K−1}E(MK​∣FK−1​)
=I{T>K−1}MK−1​

Putting it together, we get E(MT​∣FK−1​)=I{T>K−1}MK−1​+∑j=0K−1​Mj​I{T=j}
=I{T>K−2}MK−1​+∑j=0K−2​Mj​I{T=j}

We can do this argument again conditioning on FK−2​ to get E(MT​∣FK−2​)=E(E(MT​∣FK−1​)∣FK−2​)
=I{T>K−3}MK−2​+∑j=0K−3​Mj​I{T=j}

This can be iterated until we arrive at E(MT​∣F0​)=M0​

However, T is not always bounded, such as in the betting game we first introduced. So when is the optional sampling theorem valid?

Consider Tn​=min{T,n}
MT​=MTn​​+MT​I{T>n}−Mn​I{T>n}

E(MTn​​)=E(M0​) since Tn​ is bounded, but what about the other terms? The first one approaches 0 essentially because I{T>n} approaches 0 as n→∞.

So the problematic term for our nice result is E(Mn​I{T>n}), which does not necessarily approach 0. In our doubling betting example, I{T>n}=2−n and Mn​=1−2n, so we get 2−n(1−2n), which does not approach 0.

Optional Sampling Theorem: Suppose M0​,M1​,… is a martingale with respect to {Fn​} and T is a stopping time satisfying P{T<∞}=1, E(∣MT​∣)<∞, and limn→∞​E(∣Mn​∣I{T>n})=0, then E(MT​)=E(M0​).

Example:
Let Xn​ be a simple random walk on {0,…,N} with absorbing boundaries, let X0​=a, and let T=min{j:Xj​=0 or N}

Since Xn​ is bounded, we know immediately E(MT​)=E(M0​)=a and E(MT​)=NP{XT​=N}

Therefore, P{XT​=N}=Na​

Now let Mn​=Xn2​−n
E(Mn+1​∣Fn​)=E(Xn+12​−(n+1)∣Fn​)=Xn2​+1−(n+1)=Mn​ (using this), so this is a Martingale

Using the same T as before, Mn​ is no longer bounded, however we can show there exists C<∞ and ρ<1 such that P{T>n}≤Cρn

Since ∣Mn​∣≤N2+n, we can show E(∣MT​∣)<∞ and E(∣Mn​∣I{T>n})≤Cρn(N2+n)→0

Hence, E(MT​)=E(M0​)=a2

Since E(MT​)=E(XT2​)−E(T)=N2P{XT​=N}−E(T)=aN−E(T), we see E(T)=a(N−a)

Uniform Integrability

limn→∞​E(∣MT​∣I{T>n})=0 is hard to verify, so we’d like to find some easier conditions

Suppose we have X with E(∣X∣)<∞,
limK→∞​E(∣X∣I{∣X∣>K})=limK→∞​∫K∞​∣x∣dF(x)=0

We say X1​,X2​,… is uniformly integrable if for every ϵ>0 there is some K with E[∣Xn​∣I{∣Xn​∣>K}]<ϵ for each n, where K depends on ϵ (not n)

If Xn​ is uniformly integrable then for every ϵ>0 there is some δ>0 where P(A)<δ⟹E(∣Xn​∣IA​)<ϵ for each n

To show this, let δ=ϵ/(2K), so if P(A)<δ then
E(∣Xn​∣IA​)≤E(∣Xn​∣IA​;∣Xn​∣≤K)+E(∣Xn​∣IA​;∣Xn​∣>K)<KP(A)+(ϵ/2)<ϵ

Example:
Consider our martingale betting strategy, with random variables W0​,W1​,W2​,…, and An​ the event {X1​=X2​=⋯=Xn​=−1}

P(An​)=2−n
E(∣Wn​∣IAn​​)=(2n−1)⋅2−n→1
This cannot satisfy the conditions for uniform integrability for any ϵ<1

Now suppose M0​,M1​,… is a uniformly integrable martingale (with respect to X0​,X1​,…) and T is a stopping time with P{T<∞}=1

We have limn→∞​P{T>n}=0
So we therefore have limn→∞​E(∣Mn​∣I{T>n})=0

Optional Sampling Theorem (again): Suppose M0​,M1​,… is a uniformly integrable martingale with respect to {Fn​} and T is a stopping time with P{T<∞}=1 and E(∣MT​∣)<∞, then E(MT​)=E(M0​)

If X1​,X2​,… is a sequence of random variable and there is C<∞ such that E(Xn2​)<C for each n, then the sequence is uniformly integrable

To show this with our previous definition, let δ=ϵ2/4C and suppose P(A)<δ
E(∣Xn​∣IA​)=E[∣Xn​∣I(A∩{∣Xn​∣≥2C/ϵ})]+E[∣Xn​∣I(A∩{∣Xn​∣<2C/ϵ})]
≤(ϵ/2C)E[∣Xn​∣2I(A∩{∣Xn​∣≥2C/ϵ})]+(2C/ϵ)P(A)
≤(ϵ/2C)E(∣Xn​∣2)+(2C/ϵ)P(A)<ϵ

What if we set the the signs of the harmonic series randomly?
P{Xi​=1}=P{Xi​=−1}=1/2
Mn​=∑j=1n​j1​Xj​

This is a martingale, since each Xn​ has mean 0

E(Mn2​)=Var(Mn2​)=∑j=1n​Var(j1​Xj​)=∑j=1n​j21​<∞
So this is uniformly integrable

Martingale Convergence Theorem

This theorem states when a martingale converges to a limiting random variable M∞​. Let’s use Polya’s urn as an example

Let 0<a<b<∞, suppose that Mn​<a, let T=min{j:j≥n and Mj​≥b}, and Tm​=min{T,m}
For m>n, the optional sampling theorem says E(MTm​​)=Mn​<a
But E(MTm​​)≥E(MTm​​I{T≤m})=E(MT​I{T≤m})≥bP{T≤m}
So P{T≤m}<a/b

This is true for all m, so P{T<∞}≤ba​
In other words, with probability 1−(a/b) the proportion of red balls never gets as high as b
If it does go up to b (with probability a/b), the inverse of this argument says it’ll drop back down to a with probability 1−a1−b​

The probability this continues happening is limn→∞​(ba​)n(1−a1−b​)n=0
This tells us the proportion cannot fluctuate infinitely between any two numbers, i.e. M∞​ exists
It happens to be we can also prove that this setup results in a uniform distribution directly

Martingale Convergence Theorem: Suppose M0​,M1​,… is a martingale with respect to {Fn​} such that there exists C<∞ with E(∣Mn​∣)<C for all n. There there exists a random variable M∞​ such that limn→∞​Mn​=M∞​.

Fix a<b and think of Mn​ as representing the cumulative results of a fair game
Whenever Mn​<a, keep betting 1 until Mn​>b, then stop until Mn​<a again

Our winnings are then Wn​=∑j=1n​Bj​(Mj​−Mj−1​), where Bj​ is 0 or 1 and Mj​−Mj−1​ is ±1

Note that Wn​ is a martingale and Wn​≥(b−a)Un​−∣Mn​−a∣ where Un​ denotes the number of “upcrossings” (passes between a and b)

E(W0​)=E(Wn​)≥(b−a)E(Un​)−E(∣Mn​−a∣)
E(∣Mn​−a∣)≤E(∣Mn​∣)+a≤C+a
E(Un​)≤b−aE(W0​)+C+a​

This holds for all n, so the expected number of upcrossings is bounded, meaning the number of upcrossings is always finite

Note that the martingale property E(Mn​)=E(M0​) does not imply that E(M∞​)=E(M0​), such as in the martingale betting strategy W∞​=limn→∞​Wn​=1=E(W0​)

If Mn​ is a uniformly integrable martingale then M∞​=limn→∞​Mn​ exists and E(M∞​)=E(M0​)

Example:
Let Mn​ be the proportion of red balls in Polya’s urn and suppose that at time n=0 there are k red balls and m green balls. Since Mn​ is bounded, it is uniformly integrable, and Mn​ approaches M∞​ with E(M∞​)=E(M0​)=k/(k+m)

Example:
Let X1​,X2​,… be independent random variables with P{Xi​=3/2}=P{Xi​=1/2}=21​

Let M0​=1 and for n>0, let Mn​=X1​…Xn​
Note that E(Mn​)=E(X1​)…E(Xn​)=1
E(Mn+1​∣Fn​)=E(X1​…Xn+1​∣Fn​)=X1​…Xn​E(Xn+1​∣Fn​)=Mn​
Therefore, Mn​ is a martingale with respect to X1​,X2​,…
Since E(∣Mn​∣)=1, the conditions of the martingale convergence theorem hold and Mn​→M∞​ for some M∞​

Is Mn​ uniformly integrable?

lnMn​=∑j=1n​lnXj​
E(lnXi​)<0⟹lnMn​→−∞
Therefore Mn​→0

E(M0​)=E(M∞​), i.e. Mn​ is not uniformly integrable

A normal problem in statistics is estimating the mean θ of a distribution given Y1​,Y2​,Y3​,…

In Bayesian statistics, the parameter θ is taken to be a random variable taken from a prior distribution

Under the prior distribution, E[θ]=μ, and let M0​=μ and Mn​=E[θ∣Y1​,…,Yn​]

Mn​ is a martingale and the conditional distribution on Mn​ is called the posterior distribution

We also know limn→∞​Mn​=M∞​

Maximal Inequalities

If Mi​ is a sequence of random variables, defined the maximum processes as Mn​=max{M0​,…,Mn​} and Mn∗​=max{∣M0​∣,…,∣Mn​∣}

Maximal inequalities relate probabilities or expectations for Mn​,Mn∗​ to Mn​,∣Mn​∣ respectively

Reflection Principle: Suppose Xi​ are independent random variables whose distributions are symmetric about the origin, and let M0​=0 and Mn​=X1​+⋯+Xn​. For every a>0, P{Mn​≥a}≤2P{Mn​≥a}

To prove this, let T=min{j:Mj​≥a}
P{Mn​≥a}=∑j=0n​P{T=j}
P{Mn​≥a}=∑j=0n​P{T=j,Mn​≥a}=∑j=0n​P{T=j}P{Mn​≥a∣T=j}
The independence and symmetry of Xi​ shows that P{Mn​≥a∣T=j}≥P{Mn​−Mj​≥0∣T=j}=P{Mn​−Mj​≥0}≥21​ (noting that Mj​ can be greater than a makes this easier to understand)

Doob’s Maximal Inequality: Suppose Mi​ is a nonnegative submartingale with respect to Fn​. Then for every a>0, P{Mn​≥a}≤aE[Mn​]​

Let Aj​ denote the Fj​-measurable event {T=j} (same T as before),
E[Mn​]≥E[Mn​I{T≤n}]=∑j=0n​E[Mn​IAj​​]
E[Mn​IAj​​]=E[E(Mn​IAj​​∣Fj​)]=E[E(Mn​∣Fj​)IAj​​]≥E[Mj​IAj​​]≥E[aIAj​​]=aP(Aj​)

So E[Mn​]≥∑j=0n​aP(Aj)​=aP{Mn​≥a}

If Mi​ is not necessarily nonnegative, we cannot immediately use the inequality, but there’s still an extension

If E[∣Mn​∣r]<∞ then ∣Mn​∣r is a submartingale,
E[∣Y∣r∣Fn​]≥∣E[Y∣Fn​]∣r
E[∣Mn+1​∣r∣Fn​]≥∣E(Mn+1​∣Fn​)∣r=∣Mn​∣r

Likewise, if E[eY]<∞,
E[eY∣F]≥eE(Y∣F)
E[ebMn+1​∣Fn​]≥eE(bMn+1​∣Fn​)=ebMn​ for all b

Doob’s Maximal Inequality (again): Suppose Mi​ is a martingale with respect to Fn​, then for every a,b>0 and r≥1,

  • P{∣Mn​∣≥a}≤arE[∣Mn​∣r]​
  • P{Mn​≥a}≤ebaE[ebMn​]​

Example:
Let Sn​=X1​+⋯+Xn​ denote a simple random walk in Z and let b=1/n​

Sn​ is a martingale so we have,
P{max{S1​,…,Sn​}≥an​}≤e−aE[eSn​/n​]
E[eSn​/n​]=E[e(X1​+⋯+Xn​)/n​]=(E[eX1​/n​])n=(2e1/n​+e−1/n​​)n
Taylor series shows that 2e1/n​+e−1/n​​=1+2n1​+O(n21​)
limn→∞​E[eSn​/n​]=limn→∞​[1+2n1​+O(n21​)]n=e1/2

Hence,
P{max{S1​,…,Sn​}≥an​}≤Ce−a, i.e. the random walk in Z is recurrent
