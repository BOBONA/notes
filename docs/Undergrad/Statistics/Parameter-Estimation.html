Obtaining Estimators

Our goal is to optimize the parameters of a probabilistic model given an experiment

Definition: A function of a random sample that approximates a parameter is called a statistic or an estimator. An estimator of θ is denoted θ^. The maximum likelihood estimate is denoted θe​.

Definition: The probability of a trial is called the likelihood function L(θ)=∏i=1n​fθ​(xi​) (where fθ​ is a pmf or pdf)

Poisson: fλ​(x)=x!e−λλx​, so L(λ)=∏i​(xi​)!e−λnλΣi​xi​​
Exponential: fλ​(x)=λe−λx, so L(λ)=λne−λΣi​xi​
Uniform: L(θ)=θn1​ if 0≤xi​≤θ or 0 otherwise

Example: To estimate θ on the uniform distribution [0,θ], we simply take maxxi​
It’s pretty intuitive how this maximizes L(θ)

Bernoulli is perhaps the most intuitive, L(p)=p∑i​Xi​(1−p)n−∑i​Xi​
If we get heads in an experiment of n trials, then p^​=nk​

We can do this more generally this by taking the derivative of out formula (use the product rule) and finding a local maxima

X=i=0∑n​Xi​, L(p)=pX(1−p)n−X
dpdL​=XpX−1(1−p)n−X−pX(n−X)(1−p)n−X−1=0
XpX−1(1−p)n−X=pX(n−X)(1−p)n−X−1
X(1−p)=p(n−X)
p=nX​

Ta-Da! Math tells us something we already know but in a more complicated way :)

We can use regular calculus techniques to verify that setting the derivative of a function to 0 results in a global maximum

We can also do something neat by maximizing the log-likelihood e(p)=logL(p), which gives us the same result (since it’s monotonic) in an easier way. This is smart, because it allows us to rewrite our ∏​ expression into a ∑​ expression, and moves the exponents to coefficients.

e(p)=Xlogp+(n−X)log(1−p)
e′(p)=pX​−1−pn−X​
X(1−p)=p(n−X)
p=nX​

This is almost always a good technique for analyzing L(…)
When we do this analysis on Poisson, we also get the sample mean λ^=μ

Recall the example earlier on the uniform distribution. Since this function is not differentiable, we had to take an order statistic on the trial, maxxi​. A similar idea for the exponential distribution, where θe​=ymin​.

To do this in general with a multivariate distribution, we set all partial derivatives to 0

The Method of Moments

The method of moments is often more tractable than the method of maximum likelihood when the underlying model has multiple parameters

Suppose we have s unknown parameters θ1​,…,θs​. The first s theoretical moments of Y, if they exist, are E(Yj)=∫−∞∞​yj⋅fY​(y;θ1​,…,θs​)dy;. This gives us s equations E(Yi)=gi​(θ1​,…,θs​)

We also have sample moments n1​∑i=1n​yij​

The sample moments can be used as approximations for the theoretical moments, giving us a system of s equations

Interval Estimations

The issue with point estimations is they do not tell us the reliability of our estimations. Confidence intervals let us quantify uncertainty in an estimator

We’ve already looked at confidence intervals in the context of CLT
If we want to find an average to fall into an interval with probability α, we can use CLT to get (yˉ​−zα/2​⋅n​σ​,yˉ​+zα/2​⋅n​σ​) (where P(Z≥zα​)=α)

The same idea can apply to other distributions, like large-sample binomial random variables

Theorem: Let k be the number of successes in n independent trials (where n is large). An 100(1−α)% confidence interval for p is

[nk​−zα/2​n(k/n)(1−k/n)​​,nk​+zα/2​n(k/n)(1−k/n)​​]

This is effectively the same equation listed above, as the standard deviation of a binary random variable is p(1−p)​

Note that when estimating intervals from data, we’re more accurate saying the chance that the interval aligns with the true parameters, not vice versa. In other words, the true value of the parameters is a fixed fact, while our estimation comes from a random procedure.

In popular press, estimates include a margin of error, which is typically half the maximum width of a 95% confidence interval. The margin of error associated with an estimate nk​ is d=2n​zα/2​​

It’s important to note that the values within a margin of error are not equal: If a political survey over 1000 people reveals Bob is winning 50% to 48% with a 3% margin of error, we cannot say that the race is a tie. With the numbers the text uses, Bob has a 90% chance of winning.

How do we choose n for an experiment with the binomial distribution? We’d like to minimize n such that P(∣X/n−p∣≤d)=1−α

We transform the inequality to obtain p(1−p)/n​d​=zα/2​, implying n=d2zα/22​p(1−p)​. Since p(1−p)≤41​, we can use n=4d2zα/22​​ as an acceptable bound

Properties of Estimators

Maximum likelihood and the method of moments often yield different estimators. Which should we use? What’s a good estimator and is there a best one?

Biasedness

Definition: An estimator θ^=h(Y1​,…,Yn​) is unbiased if E(θ^)=θ for all θ

If limn→∞​E(θ^)=θ then we say θ^ is asymptotically unbiased

We can sometimes construct an unbiased estimator directly from a biased estimator

Example: Is σ^2=n1​∑i=1n​(Yi​−Y^)2 unbiased (normal distribution)?
E(σ^2)=E[n1​∑i=1n​(Yi​−Yˉ)2]
=E[n1​∑i=1n​(Yi2​−2Yi​Yˉ+Yˉ2)]
=E[n1​∑i=1n​Yi2​−nYˉ2]
=n1​[∑i=1n​E(Yi2​)−nE(Yˉ2)]
=n1​[∑i=1n​(σ2+μ2)−n(nσ2​+μ2)]
=nn−1​σ2

So σ^2 is biased (but not asymptotically)
The unbiased version is often called the sample variance denoted S2=n−11​∑i=1n​(Yi​−Yˉ)2

The sample standard deviation is denoted S=n−11​∑i=1n​(Yi​−Yˉ)2​and is the most common estimator for σ, although ironically it is biased (taking the square root introduces a downward bias).

So great, we’ve figured out how to unbias an estimator. Now how do we choose between unbiased estimators?

Efficiency

Besides biasedness, we can also measure the precision of an estimator in terms of its variance

Definition: Between two unbiased estimators, if Var(θ^1​)<Var(θ^2​) then we say θ^1​ is more efficient than θ^2​. The relative efficiency of θ^1​ with respect to θ^2​ is Var(θ^2​)/Var(θ^1​)

An obvious question (that Shahriar waved away in class for some reason) is whether we can identify an estimator with the smallest variance

Cramér-Rao Inequality: Let fY​(y;θ) be a continuous pdf with continuous first-order and second-order derivatives. Also, suppose that the set of y values, where fY​(y;θ)=0, does not depend on θ.

Var(θ^)≥{nE[(∂θ∂lnfY​(Y;θ)​)2]}−1={−nE[∂θ2∂2lnfY​(Y;θ)​]}−1

Definition: Let Θ be the set of all unbiased estimators for fY​(y;θ). We say that θ^∗ is a best or minimum-variance estimator if θ^∗∈Θ and Var(θ^∗)≤Var(θ^) for all θ^∈Θ.

The unbiased estimator θ^ is efficient if Var(θ^) equals the Cramér-Rao lower bound for fY​(y;θ). The efficiency of θ^ is the ratio of the lower bound for fY​(y;θ) to Var(θ^).

Note that it’s possible for the best estimator to not be efficient (meaning no estimators can reach the Cramér-Rao lower bound)

Sufficiency

Suppose that a random sample of size n is taken X1​=k1​,…,Xn​=kn​ from the Bernoulli pdf pX​(k;p)=pk(1−p)1−k. The maximum likelihood estimator is p^​=(n1​)∑i=1n​Xi​, so our maximum likelihood estimate is pe​=(n1​)∑i=1n​ki​

We’re interested in the conditional probability P(X1​=k1​,…,Xn​=kn​∣p^​=pe​)=P(p^​=pe​)P(X1​=k1​,…,Xn​=kn​)​
P(X1​=k1​,…,Xn​=kn​)=pnpe​(1−p)n−npe​
P(p^​=pe​)=P(∑i=1n​Xi​=npe​)=(npe​n​)pnpe​(1−p)n−npe​
so our conditional probability equals (npe​n​)1​

Our estimator is sufficient, because (npe​n​)1​ is not a function of p
This conceptually tells us that everything our data can tell us about p is contained in pe​, since otherwise the joint pdf P(X1​=k1​,…,Xn​=kn​) is entirely a function of k and p

Definition: The statistic θ^=h(X1​,…,Xn​) is sufficient for θ if L(θ)=∏i=1n​pX​(ki​;θ)=pθ^​(θe​;θ)b(k1​,…,kn​)

A one-to-one function of a sufficient statistic is also sufficient, therefore we can construct an unbiased estimator for θ from a sufficient but biased statistic on θ

Sometimes this definition is difficult to use, since our statistic might have a difficult pdf. The following theorem is an alternative factorization criterion

Theorem: The statistic θ^=h(X1​,…,Xn​) is sufficient if and only if there are functions L(θ)=g[h(k1​,…,kn​);θ]⋅b(k1​,…,kn​)

This works because we are able to “convert” the g portion to include the pdf of θ^

If a sufficient estimator θ^S​ exists for θ then we know an MLE for θ will maximize g(θe​;θ) and therefore be a function of θe​. It follows that maximum likelihood estimators are functions of sufficient estimators, which is an important justification for preferring them over method of moments estimators. (Would this imply they are often also sufficient, according to this statement above)

Rao-Blackwell: The variance of every unbiased estimator based on a sufficient estimator will necessarily be less than the variance of every unbiased estimator that is not a function of a sufficient estimator. This lets us restrict our search for estimators.

Consistency

It’s sometimes important to consider the asymptotic behavior of estimators, in case they have a problem that arises in the limit

For example, earlier we defined the term asymptotically unbiased

Definition: An estimator θ^n​=h(W1​,W2​,…,Wn​) is consistent for θ if it converges in probability to θ, i.e. limn→∞​P(∣θ^n​−θ∣<ϵ)=1 for all ϵ>0

We can define this similarly by saying there exists an n(ϵ,δ) such that P(∣θ^n​−θ∣<ϵ)>1−δ for n>n(ϵ,δ) for all ϵ>0, δ>0

This can be used as a tool to list the required number of samples given θ, ϵ, and δ

Chebyshev’s Inequality: Let W be any random variable with mean μ and variance σ2. For any ϵ>0,

P(∣W−μ∣<ϵ)≥1−ϵ2σ2​

Proof: In the continuous case, Var(Y)=∫−∞∞​(y−μ)2fY​(y)dy

Or as stated above, P(∣Y−μ∣<ϵ)≥1−ϵ2σ2​

Chebyshev’s inequality is a useful tool for proving consistency (I believe specifically for unbiased estimators). We can use it to show that a bound can be established satisfying δ
